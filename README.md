# adigitalinnovations.com

Static portfolio site for Arqan Adi, served by GitHub Pages.

- `index.html`: homepage
- `work/<project>/index.html`: one case study per project, served at `/work/<project>`
- `assets/`: fonts and images
- `CNAME`: custom domain for GitHub Pages
- `.nojekyll`: tells GitHub Pages to serve files as they are
- `404.html`: shown for any address that does not exist

Every page carries `noindex, nofollow`, so search engines will not list the site.
